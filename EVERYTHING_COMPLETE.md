## 🚀 How to Run

### **Terminal 1 - Backend**
```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```

### **Terminal 2 - Frontend**
```bash
cd frontend
npm install
npm run dev
```

### **Browser**
```
http://localhost:5173
```
