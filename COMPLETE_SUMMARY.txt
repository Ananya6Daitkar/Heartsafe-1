                         HOW TO RUN (3 STEPS)
================================================================================

STEP 1: START BACKEND (Terminal 1)
  cd backend
  python3 -m venv venv
  source venv/bin/activate
  pip install -r requirements.txt
  uvicorn main:app --reload

STEP 2: START FRONTEND (Terminal 2)
  cd frontend
  npm install
  npm run dev

STEP 3: OPEN BROWSER
  http://localhost:5173

================================================================================
                         API ENDPOINTS
================================================================================

GET /health
  Response: {"status": "online", "model_loaded": true, "api": "HeartSafe AI v1.0"}

POST /predict
  Input: ECG file (CSV or JSON with 186 values)
  Output: {
    "diagnosis": "Normal Sinus Rhythm",
    "arrhythmia_class": "N",
    "severity": "Normal",
    "confidence": 0.95,
    "bpm": 72,
    "qrs_interval_ms": 95.5,
    "ischemia_risk": 0.15,
    "ischemia_flag": false,
    "signal_data": [...],
    "all_probabilities": {...},
    "xai_weights": [...]
  }

================================================================================
                         FILE FORMATS
================================================================================

CSV FORMAT
  Single row with 186 ECG values:
  0.1,0.15,0.2,0.18,0.12,...,0.05

JSON FORMAT
  {
    "signal": [0.1, 0.15, 0.2, 0.18, 0.12, ..., 0.05]
  }
